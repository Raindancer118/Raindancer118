Ich studiere dual Wirtschaftsinformatik an der NORDAKADEMIE und arbeite dabei in der IT der Autoflug GmbH, Abschluss im März 2027. Privat baue ich vor allem Werkzeuge, mit denen KI-Agenten kontrolliert an echte Systeme kommen, und betreibe alles selbst, vom Proxmox-Server bis zur CI-Pipeline.

### Ausgewählte Projekte

| Projekt | Worum es geht | Stack |
|---|---|---|
| [nak-api](https://github.com/Raindancer118/nak-api) | CIS und Moodle der NORDAKADEMIE als eine Schnittstelle für KI-Agenten, Kommandozeile, Webportal und Android-App. Das CIS hat keine offizielle API, die Anbindung ist aus HTTP-Mitschnitten nachgebaut. | Go |
| [diary-mcp](https://github.com/Raindancer118/diary-mcp) | Langzeitgedächtnis für Claude auf PostgreSQL, mit hybrider Suche aus Volltext und Embeddings und Sync zwischen Rechnern. | Python, pgvector |
| [master-mcp](https://github.com/Raindancer118/master-mcp) | Die Admin-APIs von Cloudflare, Proxmox, Authentik, Docker und vier weiteren Diensten hinter einem MCP-Server, destruktive Aktionen sind gekennzeichnet. | TypeScript |
| [vault-mcp](https://github.com/Raindancer118/vault-mcp) | Setzt Secrets aus Bitwarden in Befehle, Dateien und HTTP-Requests ein, ohne dass das Modell sie zu sehen bekommt. | TypeScript |
| [shelved](https://github.com/Raindancer118/shelved) | Bücherregal per Foto oder Barcode erfassen, Daten aus Deutscher Nationalbibliothek, Google Books und Wikidata. Läuft auf [shelf.tstieh.de](https://shelf.tstieh.de). | Java, Spring Boot |
| [vela](https://github.com/Raindancer118/vela) | Launcher und Kontrollzentrum für Hyprland, Einstellungen per Schieberegler oder in natürlicher Sprache. | Rust |
